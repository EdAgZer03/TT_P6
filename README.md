# 🎮 Análisis Predictivo y Exploratorio de Ventas de Videojuegos

**Resumen**  
EDA y análisis comparativo de ventas globales para identificar patrones por género, consola y región.

**Objetivo**  
Detectar segmentos con mayor potencial comercial y generar criterios para priorizar lanzamientos.

---

## 🔍 Qué hice
- Limpieza y estructuración del dataset → dataset listo para análisis multivariable.  
- EDA por género, plataforma y región → identificación de tendencias y outliers.  
- Segmentación de productos → criterios para priorizar catálogo.  
- Visualizaciones y tablas resumen para decisiones de negocio.

---

## 🛠 Tecnologías
Python · Pandas · NumPy · Matplotlib · Seaborn · Jupyter Notebook
